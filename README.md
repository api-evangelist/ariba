SAP Ariba is the procurement and supply-chain collaboration business of SAP: strategic sourcing, contract management, procure-to-pay, supplier lifecycle and performance, supplier risk, catalog management, and the SAP Business Network that connects buyers and suppliers. Its API surface is one of the largest enterprise contract estates in the catalog - 114 REST APIs published in the SAP Business Accelerator Hub package SAPAribaOpenAPIs, plus 144 SOAP web services - all routed through the openapi.ariba.com gateway behind OAuth 2.0 client credentials, an application key, and a per-realm authorization grant. Ariba also authored cXML, the Commerce XML interchange standard the wider procurement market still runs on. The catalog metadata is anonymously readable; the specifications themselves are not - every OpenAPI download redirects to an SAP ID login.

**Areas:** B2B · Catalog Management · Compliance · Contracts · Enterprise · Integration · Invoicing · Procurement · Risk Management · SAP · Sourcing · Spend Analysis

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Ariba: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
